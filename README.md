# 这张相纸够不够（film-plan）

拍立得相纸要买几包、这面墙摆得下几张相框、相册内页要买多少才装得下——三件事一起算清。

- 相纸只能整包买：包数是确定的取整问题（`ceil(还差张数 ÷ 每包张数)`），多出来的就是余料，页面把余料张数与金额直接报出来。
- 名义单价（每包价 ÷ 每包张数）与实际单价（总花费 ÷ 实际成片）分开显示，各自标明口径。
- 照片墙按真实比例画出「几列 × 几行」的格子图；相框含框外廓与留缝都算进去；相框比墙大时直接报「放不下」。
- 相册按口袋数取整（内页口径 / 成品相册口径互斥）。
- 40 项结构自检（恒等式与不变量）、13 行敏感性、四种导出（CSV / Markdown / PNG 结果卡 / JSON 备份）、保存到本机与刷新恢复。

**不做什么**：不联网、不查行情价、不内置任何品牌规格；不假设相纸会过期、也不假设你什么时候拍；
不做承重与安装判定；不看照片内容；不做英寸与面积换算。

数字全部由使用者填写。默认数据、内置场景、封面与结果卡里的数字都是**虚构示例**。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 构建产物（单文件，可直接打开） |
| `template.html` / `core.js` / `ui.js` | 源码；`build.cjs` 把后两者内联进 `index.html` |
| `tests/core.test.cjs` | 核心测试：`node --test tests/core.test.cjs` |
| `cover.png` | 封面 1200×1200 |

## 本地运行

```bash
node build.cjs                 # 生成 index.html
node --test tests/core.test.cjs # 42 项核心测试
python3 -m http.server 8899    # 然后打开 http://127.0.0.1:8899/index.html
```
